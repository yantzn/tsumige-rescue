# TMGR-427 中断再開とPR作成予約

`python ai-engineering-platform/scripts/checkpoint.py <操作> <TMGRキー> --target-sha <現在のHEAD> --requirements-hash <要件ハッシュ>` を使用する。保存先は既定でGit管理外の `.agent-state/`。save は `--stage` を指定する。resume は保存済みのSHA・要件ハッシュが現在値と一致する場合にだけ保存工程を返す。要件の最新性は先に Atlassian の Verify で確認し、同じ採取済みスナップショットファイルのSHA-256を使う。再採取したファイルは取得時刻が変わるため、要件見直しを経てチェックポイントを作り直す。

PR作成前は統括がGitHubで同じ作業ブランチの既存PRを確認し、存在する場合は再利用する。存在しない場合だけ、PR_READYの証跡で reserve-pr を実行する。予約はチケットDBに一度だけ確定し、再開時に残っていれば自動再試行を停止する。GitHubへの書き込みは呼び出し側が行う。予約後に結果が不明なら人間が既存PRと実行履歴を照合する。同じ保存先を使う処理間で予約を共有する。別マシン間の排他や全工程の排他はこの保存機構の範囲外。

テストでは通常再開、SHA・要件ハッシュ不一致、予約の重複拒否、子プロセスが未確定更新中に即時終了した場合の直前状態の復旧を検証する。
