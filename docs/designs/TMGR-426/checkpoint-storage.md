# TMGR-426 チェックポイント保存

AGT-18の保存・スキーマ検証・排他を、Python標準ライブラリのSQLiteで実装する。呼び出し側はGit管理外の `.agent-state/` を保存先に指定する。チケットごとにDBを分け、短い処理を `checkpoint_transaction` 内で実行する。同一チケットを別の接続が更新中の場合は即座に失敗し、別チケットの保存には影響しない。

スキーマ版、チケットキー、工程、対象コミットSHA、要件のSHA-256を検証して保存する。正常終了で一括確定し、例外時は直前の確定状態を保持する。不正な保存済みデータは上書きせずエラーにする。

テストでは再オープン、異常入力の拒否、例外時のロールバック、同一チケットのロック競合、別チケットの利用を確認する。再開時のSHAと要件ハッシュの照合、作業全体の排他、PRの重複防止、Antigravityからの呼び出しと強制終了後の復旧はTMGR-427で扱う。
