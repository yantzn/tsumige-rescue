# レビュー規約
- code-review と fix-verificationは独立・読み取り専用とし、コードを編集しない。
- 指摘項目：ID、重要度、分類、ファイル・行、根拠、影響、修正案、回帰テスト、状態。
- P0：データ消失・重大セキュリティ欠陥。P1：主要機能・整合性欠陥。P2：テスト・性能・保守性。P3：軽微。
- 根拠がなければ「未検証」とする。
- 修正後は最新コミット、初回指摘、差分、テストをfix-verification で検証し、根本原因・副作用・設計整合性を確認する。
- 誤検知は根拠付きで却下できる。同一指摘で修正2回失敗なら人間へ相談する。
- P0/P1未解決0、CI成功、人間承認をマージ条件とする。
